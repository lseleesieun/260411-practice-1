# 🍕 분수 피자 연구소

초등학교 3학년 학생이 피자를 나누고 손님 주문을 해결하며 분수를 배우는 Streamlit 게임입니다. 피자 조각을 직접 누르고, 분수 비교와 10개 미션에 도전해 별과 셰프 등급을 모아 보세요.

## 실행 방법

Python 3.9 이상이 설치된 환경에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run streamlit_app.py
```

Windows PowerShell에서는 가상 환경 활성화에 다음 명령을 사용합니다.

```powershell
.\.venv\Scripts\Activate.ps1
```

앱이 실행되면 터미널에 표시되는 로컬 주소를 브라우저에서 엽니다.
